# 📚 Plano de Leitura

**Plataforma de curadoria de planos de leitura personalizados por autor, gênero e objetivo pedagógico.**

## 🎯 Objetivo

O `planodeleitura.com.br` é um guia inteligente para sua jornada literária. Oferecemos roteiros de leitura estruturados, com recomendações de livros, descrições detalhadas e links de afiliados para compra.

## 🚀 Funcionalidades Principais

- ✅ Planos de leitura por autor, gênero e objetivo de aprendizado
- ✅ Descrições individuais de cada livro (inspirado no Five Books)
- ✅ Links de afiliados para compra (Amazon, Kobo, etc.)
- ✅ Futuramente: Sistema de login para acompanhamento de progresso
- ✅ Futuramente: Clube de Leitura e comunidade

## 🛠️ Stack Tecnológica

- **Frontend:** Angular 18+ com TypeScript
- **Backend:** Node.js + Express com TypeScript
- **Banco de Dados:** (Em análise - PostgreSQL ou MongoDB)
- **Scraping:** Playwright para extração de dados
- **Cache:** Redis
- **Autenticação:** JWT
